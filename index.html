What is the Drum Seq-uencer?

A hands-on engineering project run by Trinity Sound. We're designing a drum machine from scratch: the circuits, the firmware, the case and the sound; and building it as a team.

Classic drum machines like the TR-808 turned electrical engineering into instruments. We want to find out what it takes to build one ourselves: how the electronics work, how the sound is shaped, and how it all fits into something you can actually play.

Different departments own different parts of the build, and everything comes together in a single instrument.

Departments

This project is split into departments, each responsible for one part of the design. Pick a team that interests you.

New to electronics or code? No problem — most of the team started here too.

Electrical

You'll take a circuit from a messy breadboard to a real, custom-designed PCB; in addition to designing discrete, custom power stages and filters.

  • PCB Design
  • Waveform Filters + Discrete Stages
  • Power Supply Design
  • DAC + ADC Stages
  • Headphone Amplifier + Balanced Line-out
  • IO Protection Circuits
  • MCU + Raspberry Pi CM Implementation
  • Output Oscilloscope

Firmware + User Interface

Give the machine its personality. You'll write the code that keeps perfect time, and shape how it feels in someone's hands, beit the screen, the knobs, the buttons.

  • Sequencer + Timing Code
  • Display + Menu Design
  • Buttons, Knobs & LEDs
  • I2C + SPI Communication Protocols
  • DMA Buffer Design
  • Latency-oriented Scheduler
  • Open Plugin Support

Enclosure

Design everything the player actually touches (the case, the panel, the knobs) until it feels as good as it looks.

  • Case & Panel Design
  • Ergonomics
  • Fabrication & Assembly
  • Design Language + Strong Branding
  • Durability
  • CNC + Laser Cutting
  • 3D-Printing

Administration

Keep the whole project on track (planning, budgets, sponsors, events) so every aspect of the project can grow.

  • Planning & Scheduling
  • Budgeting
  • Outreach & Communication
  • Sponsorships
  • Promotional Events
  • Branded-Merchandise
